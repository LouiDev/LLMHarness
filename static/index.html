With this on, approved file tool calls can read and write anywhere your user account can. Each call still asks for approval in the chat unless its rule under Tool approval says otherwise.

Tool approval

i
Think twice before letting tools run on their own. Local models, and heavily quantized ones in particular, sometimes call tools with wrong paths or made-up content. Tools are listed from harmless to risky; keep anything that changes files or runs code on "asks first" unless you trust the model and have backups.

"Asks first" pauses the reply for an Allow / Deny prompt in the chat; "runs on its own" executes the call as soon as the model makes it.
